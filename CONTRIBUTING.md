# Contributing

Thank you for your interest in Frame & Pane.

## Reporting bugs

Please include:

- Minecraft Bedrock version.
- Device or server platform.
- Frame & Pane version.
- Exact steps to reproduce the issue.
- Relevant Content Log lines.
- Screenshots or video when the problem is visual.

## Pull requests

1. Keep existing identifiers and UUIDs unless a breaking migration is intentionally required.
2. Preserve `en_US` and `es_MX` localization parity.
3. Run `python tools/validate.py` before submitting.
4. Describe gameplay changes and compatibility impact clearly.
5. Do not add third-party assets or code without a compatible license and an entry in `THIRD_PARTY_NOTICES.md`.
