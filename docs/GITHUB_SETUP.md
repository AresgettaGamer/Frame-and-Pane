## First push

```bash
git init
git add .
git commit -m "Release Frame & Pane v1.0.0"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/Frame-and-Pane.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username.
