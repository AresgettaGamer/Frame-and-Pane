## Description

# Frame & Pane

Frame & Pane expands Minecraft Bedrock building with functional window frames that can open, connect, and accept interchangeable glass panels.

## Main features

- **228 functional window blocks** across **57 materials**.
- Four layouts for every material: horizontal, horizontal four-pane, vertical, and vertical four-pane.
- Windows open and close with an empty-hand interaction.
- Adjacent horizontal windows form mirrored pairs and open together.
- Stacked vertical windows automatically connect, align their handles, and open as one column.
- Insert clear glass or any of the **16 stained-glass colors** directly into any frame.
- Replace or remove panels without destroying the frame.
- Survival-friendly stonecutter recipes for every window.
- English and Mexican Spanish translations.
- Designed for multiplayer and normal survival building.

## Crafting and usage

Place a supported building material in a stonecutter to craft any of its four window layouts.

- Interact with an empty hand to open or close a window.
- Use a glass pane or stained-glass pane on the frame to install it.
- Use a different pane to replace the current panel.
- Sneak and interact with an empty hand to remove the panel.
- Breaking the window returns its installed panel.

## Requirements

- Minecraft Bedrock Edition 1.26.30 or newer.
- Activate both the included Behavior Pack and Resource Pack.
- No other add-on is required.

## Technical note

Glass panels use lightweight internal visual entities with no AI, collision, gravity, or damage. Commands that indiscriminately remove every entity, such as `/kill @e`, also remove active panel visuals.
