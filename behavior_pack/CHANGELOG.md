# Frame & Pane — Release v1.0.0

## Release status

- Promoted from Beta v0.10.1 after stable in-game validation.
- 228 functional window-frame blocks across 57 materials and four frame layouts.
- Clear and 16 colored glass panels can be inserted and removed universally.
- Panel visuals use lightweight persistent entities without AI, collision, gravity, or damage.
- Horizontal and vertical opening, hinges, handles, stacking connections, waterlogging, drops, and stonecutter recipes retained.
- Added localized visual entity name: **Glass Panel / Panel de Cristal**.
- Added MIT license and third-party acknowledgement for Aesthetic Windows (CC0 1.0 Universal).

## Known behavior

Commands that indiscriminately remove all entities, such as `/kill @e`, also remove active visual glass-panel entities. Normal gameplay, chunk loading, and tested server operation remain stable.
