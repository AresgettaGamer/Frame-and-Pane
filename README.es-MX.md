# Frame & Pane

**Frame & Pane** es un add-on para Minecraft Bedrock que agrega marcos de ventana funcionales y abribles fabricados con 57 materiales de construcción. Cada marco puede recibir un panel de cristal transparente o de cualquiera de los 16 colores sin requerir un bloque distinto para cada color.

## Características

- 228 bloques de ventana funcionales.
- 57 materiales de marco.
- Cuatro diseños por material:
  - Ventana horizontal.
  - Ventana horizontal de cuatro paneles.
  - Ventana vertical.
  - Ventana vertical de cuatro paneles.
- Ventanas horizontales emparejadas y columnas verticales sincronizadas.
- Bisagras, manijas y conexiones verticales automáticas.
- Cristal transparente y los 16 colores de cristal tintado.
- Paneles reemplazables y retirables, con devolución del cristal anterior en Supervivencia.
- Una receta de cortapiedra para cada marco.
- Traducciones en inglés y español mexicano.

## Requisitos

- Minecraft Bedrock Edition **1.26.30 o posterior**.
- Deben estar activos el paquete de comportamiento y el paquete de recursos incluidos.

No requiere ningún otro add-on.

## Uso

- Interactúa con una ventana con la mano vacía para abrirla o cerrarla.
- Usa un panel de cristal sobre el marco para instalarlo.
- Usa otro color para reemplazar el panel actual.
- Agáchate e interactúa con la mano vacía para retirar el cristal.
- Al romper la ventana también se recupera el panel instalado.

## Nota técnica

El marco es un bloque personalizado. El cristal instalado se representa mediante una entidad visual interna y ligera, sin IA, colisión, gravedad ni daño. Los comandos que eliminan indiscriminadamente todas las entidades, como `/kill @e`, también eliminan esas entidades visuales.
